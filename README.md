### ALGO-000205: Single-exponential, polynomial-space exact SVP
- **Subfield:** Computational number theory, lattices, and topology
- **Open:** Solve exact Euclidean Shortest Vector Problem in \(2^{O(n)}\) time using only polynomial space.
- **Status:** Known single-exponential algorithms generally use exponential space; polynomial-space enumeration has \(n^{O(n)}\)-type time.
- **Type:** theory
